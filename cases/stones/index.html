CASE FILE · 2013

스스로 움직이는 돌

해명된 현상 · 편집 판단

미국 · 데스밸리

발자국 없는 사막에 남은 긴 흔적. 아주 얇은 얼음이 돌을 움직이는 순간.

전해지는 주장 / 관찰된 의문

움직임을 직접 보지 못했던 시절, 돌이 남긴 흔적만으로 이동 원인을 설명하기 어려웠다.

공식 자료에서 확인한 사실

  • 연구진은 2013년 12월 돌이 움직이는 현상을 직접 관측했다.
  • 얕은 물에 생긴 얇은 얼음판이 부서지고, 바람에 밀리면서 돌을 이동시켰다.
  • 국립공원관리청은 2014년 이 관측과 연구 결과를 소개했다.

어떻게 읽어야 할까?

흔적만 보는 것보다 실제 이동 과정과 기상 조건을 함께 관측한 것이 중요했다. 이 기록은 관측된 이동 메커니즘에 대한 설명이다.

남아 있는 질문과 한계

모든 과거 흔적의 개별 이동 과정을 재구성한 것은 아니다. 연결된 NPS 문서는 보관된 2014년 보도자료다.
